# NASA Projects Portfolio

A collection of four projects exploring NASA's open datasets through programming, data analysis, and machine learning.

## Projects

1. **Mars Weather Analysis** – Exploring weather patterns on Mars using data from the Curiosity rover.
2. **Asteroid Tracker** – Tracking near-Earth asteroids using NASA's Near Earth Object API.
3. **NASA Image Explorer** – Exploring NASA's image and video library.
4. **Exoplanet Classifier** – Applying machine learning to classify potential exoplanets.

## Technologies

- Python
- Pandas
- Matplotlib
- Plotly
- Scikit-learn
- HTML, CSS and JavaScript

## Data Sources

NASA Open Data, NASA APIs, and the NASA Exoplanet Archive.
